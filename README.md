\# siflens-sih



\## Safety Barrier \& SIF Precursor Intelligence



siflens-sih is an AI-assisted safety intelligence prototype designed for Oil India Limited (OIL).



The system analyzes safety reports to identify:



\- Activity

\- Hazard

\- Energy

\- Exposure

\- Critical Control

\- Barrier Failure

\- Potential Consequence

\- SIF Potential

\- Life-Saving Rule



It then connects semantically similar reports and identifies recurring safety-barrier failures for HSE validation.



\## Core Workflow



Report

→ Safety Understanding

→ Structured Extraction

→ SIF Assessment

→ Semantic Retrieval

→ Recurring Precursor Discovery

→ HSE Validation

→ Preventive Action
